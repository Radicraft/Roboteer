Roboteer type review

Six type systems for the game to wear alongside the new icon (emblem 9, version C: crossed axes behind a toothed disc, a white single-weight line on blueprint blue). Each system names a display face for the wordmark, titles, big numbers and the ENDGAME and payoff slams, a UI face for menus, parts and stats, and a number face for the HUD. Every face is SIL Open Font License 1.1 from Google Fonts, so each can be bundled in the app and the Godot pack the same way Barlow Condensed is today.

Everything in the phone frames below is live text over real game captures, 956 x 440 pt, the iPhone 18 Pro Max in landscape. Colours, plates and layouts stay the same in all six, so the type is the only thing that changes.

Today

One family, four files: Barlow Condensed (SIL OFL), in 800 italic for display, 700 for labels, buttons and numbers, 500 for body. Swift and Godot load the same TTFs (Roboteer/Fonts, Arena/assets/fonts). There is no second face anywhere; SF appears only as the size of SF Symbol glyphs.

  • Godot sizes are arena design units on a 1206 x 556 frame; the theme file says 1 pt = 1.383 units, so the 17-unit label is about 12 pt on the phone.
  • Floors are enforced in code: label 11 pt, body 13 pt (BroadcastType.labelFloor, bodyFloor). Any new system has to be judged at exactly those two sizes, which is what the small-size panels below do.
  • A swap is cheap: three PostScript names in DesignSystem.swift, three file names in broadcast.gd, one in broadcast_theme.tres, the kit screen pair, and UIAppFonts.

Head to head

The same four things in each display and number face, at the same size, so the widths and the moods compare directly.

Recommendation

05 Stamped plate. Big Shoulders Stencil Display is the one face here that says both things the icon says: it is cut like a steel plate stamped for a machine, and it is drafting-room stencil lettering, the same register as a white line drawing on blueprint paper. It is heavy and narrow, so it lands harder than Barlow in the slams while every layout sized for Barlow Condensed keeps its shape. Its unstencilled sibling carries the clock and the big numbers, and Archivo at condensed width is a plain, sturdy UI face that holds up at 11 and 13 pt.

Runner up: 01 Blueprint. The most literal match to the icon, and B612 Mono is the best HUD number face on the page. It loses on width: Saira Stencil One is a wide single weight, so long names and HAZARD KILL need about a third more room than today, and the slams read engineered rather than dangerous. If the owner wants more of the drafting table, take 05 and borrow B612 Mono for the clock only.
